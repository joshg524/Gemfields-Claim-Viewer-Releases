# Privacy

Gemfields Claim Viewer v0.5.17 stores cached research and viewed imagery, its bounded claims library, saved-claim bookmarks and local notes beneath `%LOCALAPPDATA%\QueenslandMiningClaimResearch`.

The reviewed v0.5.17 source contains no analytics or telemetry integration. Saved notes are not uploaded by the application.

The application may load public map imagery when it starts. It makes read-only network requests for official data searches and refreshes, roads, imagery, the public aerial catalogue and optional zone overlays. The configured endpoints and attributions are documented in `docs/DATA_SOURCES.md`. Those public services receive normal request information such as the requesting IP address, request time and user agent.

Uninstalling the program intentionally retains the local-data folder. Users may back it up or remove it manually.

This statement reflects the v0.5.17 source reviewed on 23 November 2026 and must be reviewed if telemetry, cloud synchronisation, accounts, payments or additional services are introduced.
