# Privacy

Gemfields Claim Viewer v0.5.14 stores cached research, its bounded claims library, saved-claim bookmarks and local notes beneath `%LOCALAPPDATA%\QueenslandMiningClaimResearch`.

The reviewed v0.5.14 source contains no analytics or telemetry integration. Saved notes are not uploaded by the application.

The application makes read-only network requests when users search or refresh official data, load roads or imagery, query the public aerial catalogue, or inspect optional zone overlays. The configured endpoints and attributions are documented in `docs/DATA_SOURCES.md`. Those public services receive normal request information such as the requesting IP address, request time and user agent.

Uninstalling the program intentionally retains the local-data folder. Users may back it up or remove it manually.

This statement reflects the source reviewed on 10 November 2026 and must be reviewed if telemetry, cloud synchronisation, accounts, payments or additional services are introduced.
