# Security policy

## Supported release

Only the most recent published release is intended to receive fixes. v0.5.14 is the current verified release candidate.

## Reporting a vulnerability

When this repository is published, enable GitHub private vulnerability reporting. Use the repository’s **Security → Report a vulnerability** action for security-sensitive reports. Do not publish credentials, private saved notes, personal information or exploitable details in a public issue.

Ordinary reproducible application defects may be reported through the repository’s Issues tab after it is enabled.

## Download verification

Use only release assets published in this repository and verify the SHA-256 checksum shown in the release notes. The current installer is unsigned, so a valid checksum confirms file identity but does not provide code-signing publisher assurance.
